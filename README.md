
# Competing Formal and Semantic Cues in L2 German Noun Gender Assignment

This project examines how formal and semantic cues relate to grammatical gender marking in L2 German. Using multiple learner corpora, the study investigates whether conflicting gender cues are associated with learners' accuracy, error patterns, and consistency in gender marking.

The study is being developed as a Stage 1 Registered Report.

## Research Questions

1. **Accuracy:** Is gender marking less accurate when formal and semantic cues conflict than when they converge?
2. **Error Direction:** When errors occur, do learners' gender choices align more closely with formal or semantic cues?
3. **Consistency:** How consistently do learners mark the gender of the same noun across repeated occurrences, and how does this vary across grammatical contexts?

## Methods

The study will draw on multiple error-annotated L2 German learner corpora. Corpus selection will depend on the availability of learner texts, target forms, morphological annotations, and learner identifiers.

Formal and semantic cues will be coded using criteria established from previous research. Gender-marking accuracy, error direction, and within-learner consistency will be analyzed while accounting for grammatical context and variation across learners, nouns, and corpora.

## Repository

This repository contains research protocols, annotation guidelines, and R scripts for corpus processing and statistical analysis.

Raw corpus data will not be distributed here. Access to the source corpora is subject to their respective licensing conditions.
